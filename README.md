# Viacheslav Tokarev  
**DSP & Embedded Systems Engineer** | **SAR Data Processing** | **Real-Time Perception**

I build perception systems end-to-end — from raw sensor streams and antenna physics to fixed-point firmware running unattended in the field. My expertise spans low-level embedded baseband receivers to high-level satellite SAR processing, focusing on motion-compromised systems, polarimetric data, and rigorous, measurement-driven validation. I prototype in Python/MATLAB and ship in C/C++ with strict bit-accurate parity between simulation and silicon.

## 🚀 Current Projects  
- 📡 **[BasebandManchesterDecoder](https://github.com/va-sar/BasebandManchesterDecoder)** — MATLAB reference for a robust Manchester baseband receiver: synthetic Q15 I/Q generation, timing phase search, BER/FER validation, and fixed-point Cortex-M4 deployment strategy.
- 🛰️ **[sentinel-downloader](https://github.com/va-sar/sentinel-downloader)** — Automated pipeline for downloading Sentinel-1 (SAR) and Sentinel-2 (optical) data from the Copernicus Data Space Ecosystem via modern Python APIs.
- 🌍 **[sar-optical-fusion](https://github.com/va-sar/sar-optical-fusion)** — Multisensor visualization and fusion frameworks for environmental monitoring and remote sensing analysis.

## 🎯 Engineering Principles  
- ✅ **End-to-End Ownership**: Bridging theoretical DSP with real-world hardware constraints, from mathematical models to deployed, measured code.
- ✅ **Rigorous Validation**: Prioritizing BER/FER metrics, synthetic stress datasets, and hardware-in-the-loop verification over theoretical promises.
- ✅ **Reproducible & Open**: Building transparent, documented pipelines in Python, MATLAB, and embedded C for real-world industrial and environmental impact.
